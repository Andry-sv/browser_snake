# browser_snake
простая браузерная игра, повторяющая змейку, с кастомным меню настроек и несколькими режимами

### [Сыграть прямо в браузере (GitHub Pages)](https://andry-sv.github.io/browser_snake/)

---

## Особенности проекта

- **Кастомное стартовое меню:** Адаптивное диалоговое окно настроек.
- **Гибкие настройки перед стартом:**
  - Выбор размера игрового поля (от 4x4 до 16x16).
  - Регулировка скорости игрового процесса с помощью ползунка.
  - Управление громкостью звуковых эффектов.
- Верстка на CSS, полностью независимая от сторонних UI-библиотек.
- Вся логика, анимации и обработка состояний написаны на чистом JS.

## Технологический стек

- **HTML5:** Семантическая разметка игрового интерфейса и элементов управления.
- **CSS3:** Flexbox/Grid для выравнивания меню, кастомные стили.
- **JavaScript (ES6+):** Логика меню, отслеживание событий, управление состоянием игры.

## Как запустить локально

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Andry-sv/browser_snake
   ```
2. Перейдите в папку с проектом:
   ```bash
   cd browser_snake
   ```
3. Просто откройте файл `index.html` в любом современном браузере.

## Структура проекта

```text
├── assets/          # Графические и аудио ресурсы проекта
├── index.html       # Основная разметка и структура стартового меню

├── script.js        # Логика инициализации настроек и запуска игры
└── README.md        # Документация проекта
```
